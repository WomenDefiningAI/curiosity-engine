# K–2 worksheet design

Create a page a child can use, not a mini-essay. Begin with one visible mission and short directions. Use two to six varied task blocks such as circle, match, sequence, draw, label, predict, measure, or record. Give every task enough physical answer space. Keep reading load small, use concrete nouns and active verbs, and make any answer key consistent with the tasks. A worksheet should have a meaningful visual structure; generated imagery may decorate but never supply exact labels, counts, scale, or scientific truth.
