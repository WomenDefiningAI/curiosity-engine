# Visual selection for early elementary learning

Choose the visual role before choosing a style. Use deterministic comparison for relative size or variation, deterministic sequence for actions, deterministic labels for factual parts, and an observation target for noticing. Use generated art only for story atmosphere and delight. Combine playful generated framing with code-owned text, arrows, labels, counts, and geometry. A useful visual should answer “what should the child look at or do?”; omit decorative clutter that competes with the learning action.
