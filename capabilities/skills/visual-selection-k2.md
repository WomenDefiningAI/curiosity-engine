# Visual selection for early elementary learning

Choose the visual role before choosing a style: spark imagination, observe real evidence, compare, explain a mechanism, or help the child do something. Use a reviewed public photo when reality itself is the evidence. Use generated artwork for recognizable subjects, illustrated parts, characters and story actions; it can carry the main visual meaning. Code composes the page and overlays readable labels, repeated counts, sequence order, precise geometry and response spaces. Review the combined visual for the specific relationship it teaches. A useful visual answers “what should the child look at or do?” Generic vector shapes or corner decoration do not fulfill a request for rich illustrated content.

Do not add a visual to routine parent chat, private or sensitive material, or a turn where it would only create latency. A learning response may have at most one primary visual plus one distinct printable. If a photo or diagram is already embedded in the printable, do not repeat it as a standalone visual. Every public image must retain source, item URL, creator, license, retrieval time, content hash, a purpose-specific alt description, and a passed safety/relevance review. Fail closed to another vetted source, a deterministic visual, or no visual.
