# Trusted Visual Source Strategy

This is a source-class guide, not a frozen URL catalog. Prefer current primary/authoritative sources appropriate to the topic.

## Strong default source classes

- government science agencies (for example NASA, NOAA, USGS, NIST)
- national/state parks and natural-history agencies
- museums and science centers with educational collections
- universities and peer-reviewed/open educational resources
- established educational nonprofits

## Rules

1. Verify license/reuse terms before embedding an external asset in a generated printable.
2. Preserve source/provenance metadata in the artifact spec even if the child-facing page omits citations for simplicity.
3. Prefer a deterministic redraw from verified facts when licensing is unclear.
4. Do not scrape random image search results into educational artifacts.
5. A trusted-source image can still be contextually misleading; final visual QA remains required for Tier B/C artifacts.
