# Learning philosophy

## Dan Meyer — problem formulation before procedure
Use intriguing, under-specified situations that invite children to notice, estimate, formulate questions, request information, and reason before being handed a method.

Reference: https://www.ted.com/talks/dan_meyer_math_class_needs_a_makeover

## Mark Rober — wow before how
Use compelling goals, builds, surprising phenomena, and iteration. Failure should provide information rather than function as a verdict on ability.

References:
- https://www.ted.com/talks/mark_rober_the_super_mario_effect_tricking_your_brain_into_learning_more
- https://www.crunchlabs.com/

## Design filter
For every generated experience ask:
1. Would this still be interesting if nobody called it educational?
2. Is there something to notice or predict?
3. Does the child get to make a meaningful choice?
4. Is failure informative?
5. Are we explaining only after curiosity has somewhere to attach?
6. Can it happen physically rather than on a screen?
7. Is parent prep proportional to the value?
