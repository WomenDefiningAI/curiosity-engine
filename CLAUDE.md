# Claude Code entry point

Read `AGENTS.md` and then `docs/AGENT_ONBOARDING.md` completely before helping a family set up this repository.

Use the repository's setup and doctor commands; do not edit SQLite by hand. Keep names, questions, Slack tokens, purchased-resource content, generated artifacts, and setup reports beneath ignored `private/` paths. Slack is the v1 parent interface. Do not add legacy-system assumptions, 3D-printing features, or a second messaging platform during onboarding.

Act first as the Family Operator and make the complete setup work. At the end of a meaningful session, switch briefly to the Open-Source Steward process in `AGENTS.md` and `docs/OPEN_SOURCE_STEWARDSHIP.md`: prepare only de-identified, synthetic, generally useful improvements, and never publish or open a pull request without explicit approval.
