# Everyday parent development cases

Twelve synthetic conversations cover preschoolers, siblings, short games, phone visuals, simple construction, selective artwork revisions and open follow-ups. The latter use invented topics and wording; private Slack transcripts are not fixtures. Inputs and reviewer expectations stay separate.

These are development cases, not a holdout. Scores are model estimates, not observed family outcomes. Collection exercises the normal service; Slack image/PDF delivery is verified separately.
