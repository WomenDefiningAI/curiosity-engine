# Curiosity Engine Lab

The Lab is the only place self-improvement happens. Production never rewrites itself.

Lifecycle: **propose -> offline eval -> compare -> shadow -> canary (optional) -> operator-approved promote -> rollback-ready**.

Challengers may change models, skills, prompts, tools, schemas, retrieval, orchestration, renderers, or resource strategies. Every behavioral change is a release candidate.

For ordinary family utility, start with the [live parent-usefulness pack](parent_usefulness/README.md). It captures
actual multi-turn service output and PDFs, then reviews whether the parent can use them as-is. Keep those findings
separate from the offline Lab's mechanism checks and from observed parent/child outcomes.
